## 1. 개요

### 1-1. 목적
고유 중점 트리가 없는 나라(중남미·발칸·아시아 소국 등)가 받는 **바닐라 기본(제네릭) 중점 트리를 통째로 새로 짠다.**
바닐라 기본 트리(약 56칸)는 짧고 단조롭다. 그래서 소국으로도 산업·군사·정치·외교·독립을 고르는 재미가 있게 만든다.

### 1-2. 핵심 방향
| 방향 | 내용 |
|---|---|
| 넓고 얕게 | 소갈래는 최대 5칸 사슬. 여러 갈래를 동시에 진행한다 |
| 고르는 재미 | 이념 4종 → 모델 18종 → 모델 안에서 노선 2택 1 |
| 모든 칸이 실제로 작동 | 1035칸 전부 게임 효과가 있다(문구만 있는 칸 0) |
| 눈에 보이는 보상 | 큰 칸은 이름 있는 국가 정신, 수도 건물 즉시 건설, 장비·병력 지급 |
| 조건부 갈래 | 해안·내륙·섬, 전쟁 중·전후, 괴뢰국·종주국, 수도 피점령 등 상황에 따라 열린다 |

### 1-3. 참고한 모드·트리
- **Very good generic focus policy reset**: 이념별 역사 모델(스탈린형·트로츠키형 등)로 갈래를 나누는 구조
- **Better Generic Focus Tree**: 비밀 예산, 주 개수에 비례하는 효과
- **Improved Generic Focus Tree**: 의용군, 육·해·공 우선주의, 도시화·농촌화
- **Minor Nations Reborn / Expanded GFT**: 괴뢰국 갈래, 점령지 안정화
- 바닐라 소국 트리: 스위스 국가 요새, 핀란드 방어선, 에티오피아 항전, 헝가리 왕정 복고 등

## 3. 갈래 구조

### 3-1. 산업 (151칸)
- **기초 산업** → 노동·금융 / **경공업 노선 ↔ 중공업 노선** (둘 중 하나, 각각 소비재·수출 / 제철·군수)
- **자원 개발**: 금속, 석유·고무, 합성 연료·심층 채굴, 자원 외교
- **연구**: 교류와 특허, 응용 연구 / **도시 개혁 · 농촌 개혁** (둘 다 가능, 각 10칸)
- **경제법 개혁**, **기반 시설**(전력·통신, 주 개발), **생산 효율**, **전시경제**·총동원 생산
- **지형 특화(조건부)**: 해안 공업·조선 산업(해안 주 보유), 내륙 공업(해안 없음), 섬 공업(섬 국가)
- **전후 재건**(전쟁 종료 후), **후반 기술**(로켓·핵·제트·전자)

### 3-2. 군사 (111칸)
- **육군 공통** → 현대화·장비 개발·특수부대·장성과 참모 / **소국 방어 ↔ 원정군**
  - 소국 방어: 요새선·예비군·요새와 저항
  - 원정군: 기동과 기갑·해외 전개·의용군
- **해군 공통**(해안 주 보유) → **연안 해군 ↔ 대양 해군**, 해병대·상선 호위, 해군 우선주의
- **공군 공통** → **방공 요격 ↔ 전술 폭격**, 항공 산업·항공 인력, 공군 우선주의
- **총력전**: 전시 보급·유격 항전

### 3-3. 정치 (606칸) — 트리의 중심
```
이념 뿌리(3) ─┬─ 합법 집권(2) ──┐
              └─ 내전·쿠데타(3) ─┴─ 정부 수립(2) ─ 간부 내각(3)
                                         │
                                   모델 선택(둘 중 하나가 아니라 여러 개 중 하나)
                                         │
              모델 머리(1) ─┬─ 본 사슬(5) ── 확장(4)
                            ├─ 마무리(5) ── 확장(4)
                            └─ 노선 A(4) ↔ 노선 B(4) ── 결말(3)
```
- 모델 하나는 30칸이다. 한 이념 안에서 모델은 하나만 고른다(상호배타).

| 이념 | 모델 | 노선 선택 예 |
|---|---|---|
| 공산주의 (163칸) | 스탈린형 · 트로츠키형 · 부하린형 · 아나키스트 · 자주 노선 | 대숙청 ↔ 집단 지도 / 붉은 군대 민주화 ↔ 전문 군대 |
| 민주주의 (133칸) | 사회 민주 · 자유 민주 · 기독교 민주 · 보수 민주 | 개혁 사회주의 ↔ 중도 개혁 / 고전 ↔ 사회 자유주의 |
| 파시즘 (133칸) | 프랑코형 국가주의 · 국가 조합주의 · 국가사회주의 · 성직자 국가주의 | 팔랑헤 강화 ↔ 군주파 연합 / 당 우위 ↔ 군 우위 |
| 비동맹 (163칸) | 군부 통치 · 개발 독재 · 왕정과 전통 · 농민 민중주의 · 종교 지도자 통치 | 강경파 군정 ↔ 포퓰리즘 / 절대 왕정 ↔ 보수 근대화 |

- **숨은 갈래(조건부)**: 망명 정부(수도 피점령 → 본토 해방 후 귀환), 정권 위기(전쟁 중 전쟁 지원 30% 미만), 이스터 에그

### 3-4. 외교·첩보 (78칸)
- **외교 노선** → 국제연맹 외교 / **연합국 편승 ↔ 추축국 편승 ↔ 코민테른 편승 ↔ 무장 중립 ↔ 지역 맹주** (다섯 중 하나)
  - 편승: 원조 → 동맹 → **실제 진영 가입**(그 진영 지도국이 있을 때)
  - 무장 중립: 중립 무역·국토 방위·중재와 정보·균형 외교
  - 지역 맹주: 경제 통합·군사 협력 → 진영(자체 진영 생성) → 통일 전쟁 / 연방
- **비밀 예산**·첩보전, **전쟁 목표**·전쟁 수행(전쟁 중), **강화 외교**(전쟁 중)

### 3-5. 괴뢰국·종주국·독립 (89칸)
- **괴뢰국일 때** — 자치 요구 → **협상 독립 ↔ 무장 독립 ↔ 충성 괴뢰국**, 민족 운동, 식민 행정
  - 판무관부 통치·협력정부(자치 단계에 따라 전용 소갈래)
  - 독립 국가 건설(독립 후): 행정·재정·주권, 재건, 국방
- **종주국일 때** — 괴뢰국 관리 → **직할 통치(자치도↓·수탈) ↔ 공영권(자치도↑·공동 번영)**, 괴뢰국 개발·괴뢰국 군대

## 4. 핵심 시스템

### 4-1. 집권 경로와 내전
| 경로 | 조건 | 결과 |
|---|---|---|
| 합법 집권 | 그 이념 지지율 **30% 초과** | 정부 교체 |
| 무장 봉기·민주 혁명·수도 진군 | 그 이념 지지율 **15% 초과** | 정부를 새 이념으로 바꾼 뒤 **옛 정권이 반란군으로 떨어져 나가는 내전**(규모 0.5). 플레이어는 새 정부 쪽 |
| 군부 쿠데타 | 없음 | 비동맹 정부로 교체 + 작은 내전(규모 0.3) |
- 내전 경로의 마지막 칸(혁명 정부 선포 등)은 **내전이 끝난 뒤에만** 찍을 수 있다.
- 툴팁에 빨간 「내전 발발!」 안내와 실제 내전 내용이 표시된다.

### 4-2. 국가 정신 두 가지
| 종류 | 수 | 어떻게 생기나 |
|---|---:|---|
| **이름 있는 국가 정신** | 129 | 70일 칸을 끝내면 그 **칸 이름 그대로**의 정신. 수정자 2줄(본 효과 + 갈래별 보조) |
| **갈래 정신** | 72 | 35일 칸의 % 효과가 그 칸이 속한 **갈래 이름의 정신**에 쌓인다(예: 도시 개혁, 소국 방어, 스탈린형, 연합국 편승) |
- 갈래별 보조 수정자: 산업 = 건설 속도, 군사 = 사단 조직력, 정치 = 안정도, 외교 = 정치력, 독립 = 전쟁 지원.

| 괴뢰국 | 자치도(괴뢰국 쪽), 모든 괴뢰국 자치도·안정도(종주국 쪽), 종주국 보장, 평화적 독립 | |

### 4-4. 밸런스 기준
- 한 번 받는 효과(정치력·공장·병력·경험·장비)는 넉넉하게, **계속 쌓이는 % 효과는 작게**.
- 징집 인력은 트리 전체 합 149%(0.7.0에서 267%에서 줄임). 대신 비핵심 인구·인구 증가·병력 지급으로 인력 수단을 나눴다.
- 70일 칸은 35일 칸의 약 2배 효과.
- 효과가 하나뿐인 칸은 없다(보조 효과 1개 이상).

### 4-5. 아이콘
- 칸 이름·효과 키워드로 바닐라 기본 중점 아이콘 36종 중 하나를 고른다(잠수함 → 잠수함, 영유권 → 영토 요구, 정부 교체 → 각 이념 아이콘 등).

## 5. 제작 방식 (기획 → 게임 파일)

```
design/generic_tree/data/*.json   ← 기획 데이터 (갈래·소갈래·칸 이름·효과 문구·기간·조건)
        │  check.py      : 칸 수·이름 중복·글자 수·5칸 제한 검사
        │  build_mod.py  : 효과 문구를 읽어 HOI4 스크립트로 변환
        ▼
mod/gibon_jungjeom/                ← 게임에 넣는 모드 (직접 고치지 않는다)
  common/national_focus/generic.txt   중점 1035칸
  common/ideas/                       이름 있는 국가 정신
  common/dynamic_modifiers/           갈래 정신
  common/characters/                  정치 고문
  localisation/ (10개 언어)            이름·설명·툴팁
```
- 기획 데이터는 칸마다 `{"name": "중공업 기지 완성", "effect": "군수공장 +2, 공장 생산량 +10%", "days": 70}` 형식이다.
- 효과 문구가 곧 게임 효과다. 예: `민간공장 +2` → 공장 2개, `공장 생산량 +5%` → 갈래 정신 수정자, `이웃국 영유권 주장` → 이웃 나라 주에 영유권.
- 검사 도구: `tools/validate.py`(모드 문법), `tools/test_focus_effects.py`(효과 생성 회귀 검사).
