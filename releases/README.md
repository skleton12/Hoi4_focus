## 설치

1. zip 을 내려받아 압축을 푼다.
2. `install.bat` 을 더블클릭한다.
   - 이 모드가 이미 깔린 폴더(`gibon_jungjeom`, `new_focus` 등)는 모두 그대로 갱신한다. 아무것도 옮기거나 지우지 않는다.
   - 문서\Paradox Interactive\Hearts of Iron IV\mod 에 모드를 복사한다.
3. 런처에서 「기본 중점 변경 모드」를 켜고 실행한다.

자세한 내용은 zip 안의 `설치방법.txt`. 변경 내역은 [`design/generic_tree/REPORT.md`](../design/generic_tree/REPORT.md).
